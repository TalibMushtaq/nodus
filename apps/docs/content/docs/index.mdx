## What is Nodus?

Nodus is a hybrid, offline-first peer-to-peer storage system. Files live
primarily on a Storage Node you control, sync directly between your own devices
over the local network, and use the Internet only as an enhancement — never a
hard dependency.

This site is the official documentation. Use the sidebar to browse the guides,
self-hosting instructions, and reference material.
