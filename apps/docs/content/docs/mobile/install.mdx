You need a **custom development build** to run the mobile client. Expo Go cannot
load the native modules for mDNS (`react-native-zeroconf`) and WebRTC
(`react-native-webrtc`).

## Prerequisites

- Node.js and pnpm (workspace install from the repo root).
- Android Studio / Xcode for local native builds, or an Expo account for EAS.

## Environment

Create `apps/mobile/.env` from `.env.example`:

```bash
EXPO_PUBLIC_RELAY_URL=https://your-relay.example
EXPO_PUBLIC_EAS_PROJECT_ID=your-eas-project-id
```

Non-local Relay URLs must be `https://` or `wss://`. Cleartext is allowed only
for `localhost`, `127.0.0.1`, `::1`, and the Android emulator alias `10.0.2.2`.

## Run locally

```bash
cd apps/mobile
npm start            # expo start
npm run android      # expo run:android
npm run ios          # expo run:ios
```

## EAS profiles

`eas.json` defines three profiles:

| Profile | Purpose |
| --- | --- |
| `development` | Dev client, internal distribution |
| `preview` | Internal distribution, APK |
| `production` | Store build, auto-increment version |

```bash
eas build --profile preview --platform android
```

## Native configuration

- The `android/` project is generated by Expo CNG but checked in. Minimum SDK is
  24, with Hermes and the new architecture enabled.
- `google-services.json` is required for Firebase push and is injected from
  `GOOGLE_SERVICES_JSON_FILE` via `app.config.js` on EAS.
- Two config plugins matter: `with-lan-cleartext` (writes a
  network-security-config that permits cleartext only on loopback/private
  ranges) and `with-rnscreens-fragment-factory` (required by React Navigation).

<Callout type="warn">
  The Android release build currently signs with the debug keystore
  (`android/app/build.gradle`). Generate and configure a real release keystore
  before publishing.
</Callout>
