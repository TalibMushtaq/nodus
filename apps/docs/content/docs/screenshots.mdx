These screenshots were captured from the live deployment at
`nodus.dartalib.tech` on 2026-11-27. The web client is shown with a fresh demo
account, so file lists and activity are empty by design.

## Sign in

The split-origin layout pairs a dark node-topology brand panel with a single
email + password form. The same form handles registration, which then shows the
one-time recovery phrase.

![Nodus sign-in screen with the node-topology brand panel](/screenshots/auth.png)

## Dashboard overview

The overview shows live Relay presence, storage available, online devices,
pending shards, the tombstone window, and the latest files and activity.

![Nodus dashboard overview showing a connected Relay and empty account](/screenshots/overview.png)

## Devices

Storage nodes and client devices registered to the account, with live
reachability, ping, rename, and revoke actions.

![Nodus devices screen listing client devices and storage nodes](/screenshots/devices.png)

## Settings

Appearance, browser-notification preferences, and local sync defaults.

![Nodus settings screen with appearance, notifications, and sync options](/screenshots/settings.png)
